# Manuscript package

This folder contains the five-page IEEE-style manuscript, its Chinese version, the IEEEtran class file and the final vector figures used in the paper.

## Compile the English manuscript

```bash
pdflatex main.tex
pdflatex main.tex
```

## Compile the Chinese manuscript

```bash
xelatex main_zh.tex
xelatex main_zh.tex
```

The final PDFs are included for convenient reading. Auxiliary LaTeX files and earlier manuscript drafts are intentionally omitted from the release package.
